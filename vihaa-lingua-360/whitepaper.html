Executive SummaryVIHAA LINGUA-360 • TIC

Why this platform exists

Does the same AI system behave consistently when the language changes?

AI systems are often summarized with single benchmark scores. But user experience can change when prompts are translated, dialects shift, safety boundaries differ, or a provider updates a model. VIHAA LINGUA-360 is designed to make those changes visible and reproducible.

Core principle: no fabricated benchmark scores. Provider failures remain visible. AI-judge metrics are labeled as model judgments, not objective truth or independent factual verification.

What the platform measures

  • Cross-language meaning consistency
  • Completeness and safety consistency
  • Unsupported-claim risk signals
  • Dialect/register behavior
  • Refusal consistency
  • Cross-model disagreement
  • Historical regression
  • Latency and token usage where available

What it does not claim

  • AI-judge scores are not ground truth
  • Consistency does not equal factual correctness
  • Disagreement does not reveal which model is correct
  • Dialect generation is not a substitute for native-speaker validation
  • Browser voice support is not a speech-quality benchmark by itself

Evaluation dimensions

DimensionInterpretationLimitation
Meaning consistencyWhether target-language output preserves the central meaning of a baseline response.Depends on evaluator quality and baseline quality.
CompletenessWhether important content from the baseline remains present.Baseline may itself omit important information.
Safety consistencyWhether cautions, warnings and boundaries remain comparable.Consistency does not prove safety behavior is correct.
Unsupported-claim riskWhether the target answer appears to introduce claims not supported by compared texts.Not web-grounded fact checking.

Cross-model disagreementDegree of substantive difference between two answers.Does not identify the correct answer.
Regression trendChange in evaluator signals over repeated runs.Evaluator or prompt changes can create confounds.
Factuality note: a language-consistency score should never be presented as factual accuracy. Source-grounded verification is a separate evaluation layer.

Judge design

The configured judge receives only the supplied prompt and responses for comparison. The default methodology instructs the judge not to claim independent factual verification. Judge output is stored alongside the real model answer so users can inspect both.

Human validation

For formal studies, the recommended protocol is native-speaker annotation with documented criteria, multiple reviewers, and inter-rater agreement analysis.

Advanced LabsDialect • Disagreement • Refusal • Voice

Beyond translation-only benchmarking

Dialect Intelligence

Prompts are rewritten into dialect or register variants while preserving intent. Real model responses are then compared. Current families include Telugu, Arabic, Spanish, English, and Hindi variants.

Cross-Model Disagreement

Two successful model answers for the same language are compared by a configured judge. The output highlights substantive differences without deciding which model is correct.

Refusal Consistency

Responses are classified as answered, partial/guarded, or refused. This enables cross-language inspection of whether a model changes its willingness to answer.

Voice Benchmark

Browser/device speech recognition captures spoken prompts and speech synthesis can read responses. The platform does not invent STT or TTS quality scores.

Explore Mode

Explore Mode gives users a comprehensive structured answer in their chosen language through a real configured provider. The same question can be handed to Benchmark Mode for cross-model analysis.

A user can move from “give me an answer” to “show me how this answer changes across models and languages” without leaving the platform.

Regression ObservatoryBehavior over time

AI Language Regression Observatory

Model behavior is not static. Providers can update routing, model snapshots, system policies, safety layers, or serving infrastructure. A model that performs well in one language today may behave differently later.

“Did this AI model become better or worse in this language after an update?”

VIHAA LINGUA-360 stores compact run summaries locally and can plot historical meaning-consistency signals for a selected model/language pair. The chart is a diagnostic signal, not a causal claim about a provider update.

Recommended regression protocol

  • Use a frozen benchmark pack.
  • Record exact model identifiers and provider settings.
  • Repeat each condition multiple times.
  • Version the evaluator.
  • Separate random variation from persistent shifts.
  • Investigate large changes with native-speaker review and source-grounded checks.
A time-series line can be affected by prompt changes, evaluator changes, provider routing, temperature, network retries, or model nondeterminism.

Limitations, Safety & PrivacyTransparent boundaries

Known limitations

  • Evaluator dependence: AI judges can be biased or inconsistent.
  • Translation confound: model-generated translation can alter meaning.
  • Geographic visualization: language map markers are illustrative, not population-weighted national statistics.
  • Voice support: browser and operating-system support varies.
  • Static client constraints: browser-only clients should not hold organization-wide master keys.
  • No automatic factual verification: Explore and Benchmark modes are not authoritative high-stakes sources.

Credential handling

API keys are not included in share snapshots, local summary history, or designed reports. Public production deployments should use a secure backend proxy with rate limiting and abuse protection.

Responsible reporting

Research claims should distinguish observed model behavior from causal explanations. Large differences should be reproduced, reviewed by native speakers, and checked with source-grounded evidence before publication.

No fabricated findings: this whitepaper describes the platform and methodology. It intentionally does not present invented model rankings, benchmark winners, or synthetic empirical results.
