02 / AI Skills

What you’ll actually learn

This is an AI-first course. The focus is understanding AI systems and building useful automations and agents, not generic creative-software training.

🧠

AI Fundamentals

AI, ML, Deep Learning, Generative AI, inference, tokens, context windows, hallucinations and model behavior.

🤖

LLM Models

How large language models work, how models differ, when to use cloud vs local models and how to select the right model.

⌨️

Prompt Engineering

System prompts, reusable prompt templates, structured outputs, JSON responses and task decomposition.

🔌

APIs & Webhooks

REST basics, JSON, API keys, requests, webhooks and connecting AI models to real business systems.

⚙️

n8n Automation

Triggers, nodes, conditions, HTTP requests, AI nodes, databases, scheduled workflows and production automation patterns.

📚

RAG Systems

Embeddings, chunking, vector search, document retrieval and building AI assistants that answer from private knowledge.

🕹️

AI Agents

Tool-using agents, memory, planning, actions, approvals and multi-step agentic workflows for practical business tasks.

🧪

Evaluation & Fine-Tuning Basics

When RAG is enough, when customization may help, dataset basics, testing, evaluation and quality control.

💼

AI Freelancing

Problem discovery, workflow mapping, proposals, pricing, demos, client communication, deployment and maintenance.
