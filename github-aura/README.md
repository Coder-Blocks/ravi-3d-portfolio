# ◈ GitHub Aura

GitHub Aura turns any public GitHub profile into a cinematic developer fingerprint, language constellation, repository pulse, and shareable social card — with no login, no backend, and no API key.

**Live demo:** https://coder-blocks.github.io/ravi-3d-portfolio/github-aura/

## Features

- Search any public GitHub username
- Deterministic Code Fingerprint from public profile/repository metadata
- Animated language constellation
- Public repo, star, follower and recency signals
- Recently updated repository pulse
- Shareable per-user URL using `?u=username`
- One-click 1200×630 PNG social card export
- Copy-ready social share text
- Responsive single-file app with zero build step

## Privacy

GitHub Aura reads only public GitHub profile and repository metadata through GitHub's public REST API. It does not request passwords, OAuth tokens, private repositories, or private account data. GitHub public API rate limits may apply.

## Tech

HTML5 · CSS · Vanilla JavaScript · GitHub REST API · Canvas API
